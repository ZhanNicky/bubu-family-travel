# 布布一家旅行档案

GitHub Pages 静态站点发布目录。

- 旅行首页：`index.html`
- 宁夏旅行：`trips/ningxia-2026/index.html`

## 宁夏版本

- **v1.0**：`trips/ningxia-2026/v1.0.html`，升级前的完整页面存档，保留截至 2026-09-18 的车票信息。
- **v2.0**：`trips/ningxia-2026/index.html`，亲子旅行手账。七天日期导航、每日时间线、住宿提示、动态沙漠插画、可勾选行前清单和手机底部导航。
- 实际出行 2026-10-01 至 10-07，共 7 天 6 晚；9 月 30 日为行前准备。旧版作为快照保留原文。
- 清单与探险本的勾选保存在当前浏览器，不会跨手机同步；无脚本时仍可阅读完整行程。
- 支持系统“减少动态效果”，也可在封面手动暂停动画。

## 手动更新 GitHub

在仓库中逐个打开对应文件，通过铅笔按钮替换内容并 Commit changes；v1.0.html 是新增文件，可在该文件夹使用 Add file → Upload files 上传。

本次需要同步 3 个网页文件：

1. `index.html`（旅行主页）
2. `trips/ningxia-2026/index.html`（新版旅行页）
3. `trips/ningxia-2026/v1.0.html`（旧版存档）

可同时同步此 README。v2.0 样式、插画和脚本均包含在 HTML 内，无需另外上传依赖或安装构建工具。原来的分享网址继续指向 v2.0。
